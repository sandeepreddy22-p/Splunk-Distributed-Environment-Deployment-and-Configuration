
# 01. License Manager Configuration

**Objective**

To configure a centralized License Manager and connect the required Splunk Enterprise components to manage license usage.

## Components

- Cluster Manager
- Indexers
- Search Heads
- Deployer
- Deployment Server
- Monitoring Console

## Configuration File

server.conf

## Configuration Steps

1. Log in to the Splunk instance.
2. Open the server.conf file.
3. Configure the License Manager URI.
4. Save the configuration.
5. Restart Splunk if required.
6. Verify connected license peers in the License Manager interface.

## Validation

- Check License Manager connectivity.
- Verify connected license peers.
- Check license usage and status.

## Result

Successfully configured centralized license management for the applicable Splunk Enterprise instances.
