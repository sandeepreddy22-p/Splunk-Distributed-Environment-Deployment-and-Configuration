
# Splunk Distributed Environment – Documentation

## Project Overview

This documentation covers the configuration and integration of a Splunk Enterprise Distributed Environment.

The project includes configuring different Splunk components, establishing communication between the components, configuring Indexer Discovery, and validating the complete distributed environment.

## Topics Covered

1. License Manager Configuration
2. Cluster Manager Configuration
3. Indexer Cluster Configuration
4. Search Head Cluster Configuration
5. Connecting Search Heads to Indexer Cluster
6. Configuring Indexer Discovery through Deployment Server
7. Enabling Indexer Discovery in Cluster Manager
8. Enabling Indexer Discovery in Management Components
9. Connecting All Splunk Tiers
10. End-to-End Environment Validation

## Environment Components

- License Manager
- Cluster Manager
- Indexers
- Search Heads
- Deployer
- Deployment Server
- Monitoring Console
- Heavy Forwarder
- Universal Forwarder

## Documentation Structure

Each topic is documented separately with:

- Objective
- Configuration steps
- Configuration files
- Commands
- Validation
- Screenshots
- Results

## Project Outcome

Configured and integrated the required Splunk Enterprise components in a distributed environment and performed connectivity and configuration validation.
