
# 07. Enabling Indexer Discovery in Cluster Manager

## 1. Objective

Configure the Cluster Manager to support Indexer Discovery requests from Forwarders.

## 2. Configuration Activities

1. Log in to the Cluster Manager.
2. Configure Indexer Discovery settings.
3. Configure the required shared security key.
4. Verify the discovery configuration.
5. Ensure Forwarders can communicate with the Cluster Manager.

## 3. Validation

- Verify Indexer Discovery configuration.
- Check discovery connectivity.
- Confirm that Forwarders can discover available indexer peers.

## 4. Result

Successfully configured Indexer Discovery on the Cluster Manager.
