
# 04. Splunk Search Head Cluster Configuration

## 1. Objective

Configure multiple Search Head instances as a Search Head Cluster.

## 2. Configuration Activities

1. Log in to the Search Head instances.
2. Configure Search Head Cluster members.
3. Configure the required cluster security key.
4. Establish communication between Search Head members.
5. Configure the Deployer.
6. Verify Search Head Cluster status.
7. Identify the SHC Captain.

## 3. Important Concepts

- Search Head Cluster
- SHC Members
- SHC Captain
- Deployer
- Cluster Security Key

## 4. Validation

- Verify Search Head Cluster members.
- Check captain status.
- Verify cluster communication.

## 5. Result

Successfully configured the Search Head Cluster and verified member connectivity.
